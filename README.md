# Data Engineering Web Foundation

A semantic HTML5 webpage outlining core concepts in data pipeline architecture, dimensional modeling, and essential technical stacks like SQL and Python. This project serves as a foundational academic portfolio piece demonstrating clean code and web standards.

## Features
- Fully semantic HTML5 structure (`<header>`, `<main>`, `<section>`, `<footer>`).
- 100% compliant with W3C Markup Validation standards.
- Fully accessible and validated against the WAVE Web Accessibility Evaluation Tool.
- Responsive baseline styling suitable for analytical dashboards and documentation.

## How to Run in VS Code
1. Open VS Code and select **File > Open Folder** to load the project directory.
2. Navigate to the Extensions marketplace (`Ctrl+Shift+X`) and install the **Live Server** extension by Ritwick Dey.
3. Open `index.html` in the main editor window.
4. Right-click anywhere inside the HTML code and select **Open with Live Server** (or use the keyboard shortcut `Alt+L`, `Alt+O`). 
5. Your default web browser will automatically open and display the live webpage.
